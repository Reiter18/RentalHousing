# Аренда жилья

Учебный проект: объекты недвижимости, договоры аренды, платежи, коммунальные счета и обмен документами между арендатором и арендодателем.

## Назначение и сценарии

- **Арендодатель** добавляет объекты, заключает договоры, ведёт платежи и коммунальные счета, обменивается документами с арендатором.
- **Арендатор** смотрит свои договоры, вносит платежи, видит коммунальные счета, загружает и скачивает документы.

## Экраны

1. **Вход и регистрация** (`/login`)
2. **Объекты** (`/`) — список объектов недвижимости
3. **Договоры** (`/leases`) — список договоров аренды
4. **Договор** (`/leases/:id`) — сведения о договоре и вкладки «Платежи», «Коммунальные счета», «Документы»

## Стек

Python + FastAPI, PostgreSQL + SQLAlchemy, React + TypeScript (Vite), библиотека UI-компонентов Mantine, Git.

## Структура frontend (`frontend/src`)

- `pages/` — страницы (по одной на экран)
- `components/` — общие компоненты (шапка с меню)
- `data/demo.ts` — демонстрационные данные (на этом этапе API ещё нет)

## Запуск frontend

Нужен Node.js 18+.

```
cd frontend
npm install
npm run dev
```

Откройте http://localhost:5173
